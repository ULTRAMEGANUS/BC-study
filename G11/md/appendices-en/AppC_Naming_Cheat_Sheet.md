# Appendix C — Naming Cheat Sheet｜附录 C　命名速查

## C-1　Organic Naming: The Four Steps｜有机命名四步法

1. **Find the parent chain｜找主链** — longest chain *containing the functional group*（含官能团，不只看长）。
2. **Number for lowest locants｜编号取小** — functional group beats substituents in priority（官能团位次优先最小）。
3. **Name substituents｜命名取代基** — alkyl prefixes (methyl 甲基, ethyl 乙基…); di/tri/tetra with commas between numbers, hyphens between numbers and letters（数字间逗号、数字与字母间连字符；di/tri/tetra 不计字母序）。
4. **Assemble｜组装** — substituents alphabetical, then parent + suffix（取代基按字母序 → 主链 + 后缀）。

### Priority suffixes｜后缀优先级（高 → 低）

| Priority｜优先 | Group｜基团 | Suffix｜后缀 | Position style｜位次写法 |
|---|---|---|---|---|
| 1 | carboxylic acid 羧酸 | -anoic acid | C1 fixed in –COOH |
| 2 | ester 酯 | alkyl …anoate | two-word name 双词名 |
| 3 | amide 酰胺 | -anamide | |
| 4 | aldehyde 醛 | -anal | C1 fixed in –CHO |
| 5 | ketone 酮 | -anone | propan-**2**-one |
| 6 | alcohol 醇 | -anol | propan-**1**-ol |
| 7 | alkene/alkyne 烯/炔 | -en(e)/-yn(e) | but-1-ene |
| 8 | halo/alkyl 卤/烷基 | prefixes 前缀 | 2-chloro-3-methyl… |

### Worked examples｜例

| Structure｜结构 | English name｜英文名 | 中文名 |
|---|---|---|---|
| CH₃CH₂CH₂CH₃ | butane | 丁烷 |
| CH₃CH(CH₃)CH₂CH₃ | 2-methylbutane | 2-甲基丁烷 |

## C-2　Inorganic Naming Refresh｜无机命名复习（Science 10 压缩版）

### Ionic compounds｜离子化合物

- **English order: cation first, anion second**｜英文：阳离子在前。
  - monatomic anion → -ide: NaCl sodium chloride｜氯化钠
  - polyatomic ions to know: OH⁻ hydroxide 氢氧根 · NO₃⁻ nitrate 硝酸根 · SO₄²⁻ sulfate 硫酸根 · CO₃²⁻ carbonate 碳酸根 · PO₄³⁻ phosphate 磷酸根 · NH₄⁺ ammonium 铵根 · CH₃COO⁻ acetate 醋酸根
- **Variable-charge metals**: stock number in Roman numerals — FeCl₂ iron(II) chloride 氯化亚铁; FeCl₃ iron(III) chloride 氯化铁.｜变价金属用罗马数字；中文用"亚铁/铁"区分 Fe²⁺/Fe³⁺。

### Molecular compounds｜共价化合物

- prefixes both ways: CO carbon monoxide 一氧化碳; N₂O₄ dinitrogen tetroxide 四氧化二氮（tetra 省 a → tetroxide）.｜双方都用前缀；四氧化二氮的"四"对应 tetr(a)-。

### Acids｜酸

- binary: hydro…ic — HCl hydrogen chloride(g)/hydrochloric acid(aq) 盐酸
- oxyacids: -ate → -ic acid（SO₄²⁻ → sulfuric acid 硫酸）; -ite → -ous acid（NO₂⁻ → nitrous acid 亚硝酸）

## C-3　English–Chinese Naming Order Rules｜英中命名语序对照

### The rule｜总规则

| Domain｜领域 | English｜英文 | Chinese｜中文 |
|---|---|---|---|---|
| **Inorganic 无机** | cation → anion（sodium chloride） | **anion + 化 + cation（氯化钠）— opposite 相反** |
| **Organic 有机** | same order, translated piece by piece（2-methylbutane 2-甲基丁烷） | **基本同向 identical order** |
| **Ester 酯** | alkyl → acid（methyl ethanoate） | **acid + 醇名（乙酸甲酯）— opposite 相反** |

### Error gallery｜错误示范（考试扣分实录）

| Wrong 错写 | Why wrong 为什么错 | Right 正确 |
|---|---|---|
| "chloride sodium" | Chinese order pasted into English 英文里用中文语序 | sodium chloride |
| "sulfate copper(II)" | English must put the cation first 英文必须阳离子在前 | copper(II) sulfate |
| "甲基丙烷" without locant | missing position number 缺位次 | 2-甲基丙烷 |
| "1-丙酮" | ketone numbering starts at C=O; 1 is impossible 酮位次不可能为 1 | 丙酮 / propan-2-one |
| "乙醇乙酯" | ester names must name the acid, not the alcohol 酯名必须写酸 | 乙酸乙酯 ethyl ethanoate |
| iron chloride | variable-charge metal without stock number 变价金属缺罗马数字 | iron(II) or iron(III) chloride |
