# Appendix B — Data & Quick Reference｜附录 B　数据与速查

> 🗂️ **Scope note｜范围说明**：A compressed companion for quizzes and tests. Atomic masses: 4–5 significant figures, matching the Data Booklet periodic table.｜考试随查卡。原子量取 4–5 位有效数字，与 Data Booklet 周期表一致。

## B-1　Using the Data Booklet｜Data Booklet 使用指南

| Page｜页 | What it holds｜内容 | When you reach for it｜何时用 |
|---|---|---|
| p1 periodic table 周期表 | atomic masses, symbols, groups | molar masses; electronegativity values (Pauling) are printed in each element's box｜算摩尔质量；查电负性（鲍林标度印在元素格内） |
| p2 ｜资料页 | solubility table, formulas, constants | precipitation predictions; formula checks｜沉淀预测；公式核对 |

**Reading electronegativity off p1｜从 p1 读电负性**：F 4.0 · O 3.5 · N 3.0 · Cl 3.0 · C 2.5 · S 2.5 · H 2.1 · Na 0.9 · Cs 0.7. ΔEN calculations in Ch.7 must quote these values, not textbook shortcuts.

**中文**：Ch.7 的 ΔEN 计算必须引用表上数值，不得凭印象。

## B-2　Organic Functional Groups Master Table｜有机官能团总表

| Family｜族 | Structure｜结构 | Suffix｜后缀 | Example｜例 |
|---|---|---|---|
| alkane 烷烃 | C–C only | -ane | propane 丙烷 |
| alkene 烯烃 | C=C | -ene | propene 丙烯 |
| alkyne 炔烃 | C≡C | -yne | propyne 丙炔 |
| alcohol 醇 | –OH | -anol (-ol) | propan-1-ol 1-丙醇 |
| haloalkane 卤代烃 | –X (F/Cl/Br/I) | halo- prefix 氯… | chloroethane 氯乙烷 |
| aldehyde 醛 | –CHO (terminal) | -anal | propanal 丙醛 |
| ketone 酮 | C=O (interior) | -anone | propan-2-one 丙酮 |
| carboxylic acid 羧酸 | –COOH | -anoic acid | ethanoic acid 乙酸 |
| ester 酯 | –COO– | alkyl …anoate | methyl ethanoate 乙酸甲酯 |
| amide 酰胺 | –CONH₂ | -anamide | ethanamide 乙酰胺 |
| amine 胺 | –NH₂ | amino- prefix | aminoethane 氨基乙烷 |
| benzene aromatic 芳环 | C₆H₆ ring | benzene- / -benzene | methylbenzene 甲苯 |

**Ester word order trap｜酯的双词名陷阱**：English = *alkyl* first, then *…anoate* (methyl ethanoate); 中文相反——酸名在前，醇名在后（乙酸甲酯）. The two languages are **opposite** here and nowhere else in organic naming.｜英文醇名在前、酸名在后；中文酸前醇后——有机命名中唯一一处中英语序相反。
