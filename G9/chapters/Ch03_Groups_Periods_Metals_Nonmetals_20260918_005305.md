## 2. 学习目标｜Learning Objectives

**EN — By the end of this chapter, you should be able to:**
1. Locate any element on the periodic table given its group number and period number, and vice versa.

## 3. 概念解析｜Concept Explanations

### 3.1 Group / Family 族（纵列）

**定义 Definition**：A **group**（also called a **family**）is a **vertical column** in the periodic table. There are **18 groups**, numbered 1 to 18 from left to right.
**中文**：族（也称 family）是周期表中的**纵列**，共 **18 个**，从左到右编号 1–18。

- **同族元素化学性质相似**（similar chemical properties）——这是周期表最重要的规律，Ch.4 将把它具体化到四个重要族。
- 原因【预告 Ch.5】：**主族元素的价电子数相同**（第 1 族都是 1 个、第 17 族都是 7 个），而化学性质主要由价电子数决定。
- 有些旧教材用 IA、IIA、VIIA 编号；BC 教材与考试统一使用 **1–18**。

### 3.2 Period 周期（横行）

**定义 Definition**：A **period** is a **horizontal row** in the periodic table. There are **7 periods**.
**中文**：周期是周期表中的**横行**，共 **7 个**。

- 沿一个周期从左往右走，**金属性逐渐减弱、非金属性逐渐增强**。
- **周期数 = 该元素原子的电子层数**：第 3 周期元素的电子占据 3 个电子层【预告 Ch.5】。
- 第 1 周期只有 H 与 He（第 1 层最多容纳 2 个电子）；第 6、7 周期较长，含镧系与锕系。

### 3.3 Three classes of elements 三大类元素

周期表用一条**锯齿线 / 楼梯线（zigzag line / staircase line）**把元素分成三块，见 **图 3-3**。

**① Metals 金属** — 位于锯齿线的**左下方**，约占全表 3/4（含过渡元素）。

| 性质 English | 中文 | 说明 |
|---|---|---|
| lustrous / shiny | 有金属光泽 | 新鲜表面反光（切开变暗是表面被氧化） |
| malleable | 有延展性 | 能被敲打成薄片，如铝箔、**金箔** |
| ductile | 可拉成丝 | 能被拉成细丝，如铜丝 |
| good conductor of heat & electricity | 导热、导电 | 铜做电线、铝做锅底 |
| solid at room temperature | 室温为固体 | **唯一例外：Hg 汞为液体** |
| high melting point & high density | 熔沸点高、密度较大 | 钨 W 熔点极高，用于灯丝 |

**② Non-metals 非金属** — 位于锯齿线的**右上方**（再加上左上的 hydrogen 氢）。

| 性质 English | 中文 | 说明 |
|---|---|---|
| dull / not shiny | 无金属光泽 | 硫黄、木炭都没有光泽 |
| brittle | 脆 | 固体受敲击会碎裂而**不会变形** |
| poor conductor | 不良导体 | 一般不导电、不导热，可作绝缘/隔热材料 |
| many are gases | 多为气体 | O₂、N₂、Cl₂、稀有气体；也有固体（C、S、P、I₂）与液体（Br₂） |

> **重要例外**：碳的石墨形态（graphite）能导电。所以"能导电"**不是**判断金属的绝对标准，必须结合光泽、延展性一起判断。

**③ Metalloids / semi-metals 类金属** — 沿锯齿线两侧的一条窄带。

- **BC 官方用词 semi-metal**，多数教材用 **metalloid**，**两者完全等价**，本讲义中文统一译"**类金属**"。
- 常见六种：**B 硼、Si 硅、Ge 锗、As 砷、Sb 锑、Te 碲**（沿楼梯从上往下记："**硼硅锗砷锑碲**"）。
- 性质**介于金属与非金属之间**：可能有金属光泽，但**脆、不能延展**；导电性中等且随温度等条件变化 → 称为 **semiconductor 半导体**，是计算机芯片的基础（**Si 硅**最典型）。
- **边界并不绝对**：Po 钋、At 砹有时也被列为类金属，不同教材有分歧；**BC Science 9 只要求掌握上述六种**。

### 3.4 Main-group vs Transition elements 主族元素与过渡元素

| 名称 English | 位置 Location | 中文 | 特点 |
|---|---|---|---|
| **Main-group / representative elements** | 第 **1、2、13、14、15、16、17、18** 族 | 主族元素（代表性元素） | 性质随族号**规律性强**、易预测；前 20 号元素多属主族 |
| **Transition elements** | 第 **3–12** 族 | 过渡元素 | 全是金属；熔点高、密度大，常有多种化合价，化合物常有颜色（如 CuSO₄ 蓝色） |

- 常见过渡元素：**Fe 铁、Cu 铜、Zn 锌、Ag 银、Au 金、Ni 镍、Cr 铬、Mn 锰**。
- 【预告 Ch.6】"多种化合价"（如 Fe²⁺ / Fe³⁺）是过渡元素的典型特征。

### 3.5 Special states and magnetism 状态与磁性的特例

- **室温（约 20–25 ℃）下呈液态的元素只有两种**：
  - **Hg 汞（mercury，金属）**——唯一液态金属，用于旧式温度计、荧光灯。
  - **Br 溴（bromine，非金属）**——唯一液态非金属，红棕色、易挥发、有刺激性气味。
- **易混淆的"伪液态"**：**Ga 镓**（熔点 29.8 ℃）与 **Cs 铯**（熔点 28.4 ℃）在稍热环境（手心）会熔化，但在标准室温下仍算固体。
- **室温气体**：全部稀有气体是气体；常见气体单质还有 **H₂、N₂、O₂、F₂、Cl₂**（Ch.4 详述）。
- **磁性元素**：常温下能被磁铁吸引的"铁磁性"元素主要是 **Fe 铁、Co 钴、Ni 镍**（以及它们的合金，如钢）；**绝大多数金属不能被磁铁吸引**。

### 图 3-3　三大区与锯齿线｜Three Regions & the Zigzag Line

```
          │ 1    2    13   14   15   16   17   18
   ───────┼──────────────────────────────────────
     P1   │ n                                  N
     P2   │ M    M    #    n    n    n    n    N
     P3   │ M    M    M    #    n    n    n    N
     P4   │ M    M    M    #    #    n    n    N
     P5   │ M    M    M    M    #    #    n    N
   ───────┴──────────────────────────────────────

   M = metal 金属        n = non-metal 非金属
   N = noble gas 稀有气体（非金属的一类）
   # = metalloid / semi-metal 类金属：B、Si、Ge、As、Sb、Te

   把各个 # 连起来，就是那条楼梯状的锯齿线 staircase / zigzag line：
        B ─ Si ─ Ge ─ As ─ Sb ─ Te（自上而下，阶梯向右下延伸）
   线的左侧＝金属，线的右侧＝非金属，线上的元素＝类金属
   注意两个"不老实"的元素：H 在左上角却是非金属；Al 贴着线却是金属
```

**看图要点**：锯齿线**不是直线而是一段楼梯**：每个类金属处在"金属与非金属的交界"上。**同族越往下越偏金属**——这就是"向下金属性增强"的表现。

### 图 3-4　导电性检测电路｜Conductivity Test Circuit

```
    ┌────────[ battery 电池 ]────────┐
    │                                │
    │                                │
    │            ┌──────┐            │
    │            │ lamp │            │
    │            │ 灯泡 │            │
    │            └──┬───┘            │
    │               │                │
    └───────────────┼────────────────┘
                    │
        ┌───────────┴───────────┐
        │   待测样品 sample     │   ← 把样品串接进电路
        └───────────────────────┘

   灯泡明亮         → good conductor 良导体      → 多为金属 metal
   灯泡不亮         → poor conductor 不良导体    → 多为非金属 non-metal
   灯泡暗或时亮时暗 → semiconductor 半导体       → 多为类金属 metalloid（如 Si）
   对照实验 control：用一段已知铜线接入，确认电路本身完好
```

**看图要点**：必须**把样品串在电路里**（电路要闭合才有电流）；先用铜线做对照，排除"灯泡坏了、电池没电"这类干扰。

### 图 3-5　例题：按性质描述分类并定位｜Worked Example

**题目**：根据下列描述，判断每种样品属于 metal / non-metal / metalloid，并说明它在周期表上的大致位置。

| 样品 | 观察描述 Observation | 分类 Class | 位置 Location | 判断理由 Evidence |
|---|---|---|---|---|
| A | 银白有光泽、能被拉成细丝、灯泡接上就亮 | **metal 金属** | 锯齿线左侧 | 有光泽 + ductile 可拉丝 + 良导体，三条同时满足 |
| B | 暗灰色粉末、用锤敲即碎、接入电路灯泡不亮 | **non-metal 非金属** | 锯齿线右侧 | dull 无光 + brittle 脆 + 不良导体 |
| C | 灰黑有光泽但很脆、灯泡微微发亮 | **metalloid 类金属** | 锯齿线上（如 Si、Ge） | 有光泽却脆、导电性介于两者之间 → semiconductor |
| D | 无色气体、完全不导电 | **non-metal 非金属** | 右上角或第 18 族 | 气体 + 不良导体（多为非金属） |
| E | 有光泽、能被磁铁吸引、可导电 | **metal 金属**（Fe / Co / Ni） | 第 8–10 族（过渡元素） | 磁性只出现在 Fe、Co、Ni 等少数金属中 |

> **易错提醒**：样品 E **有磁性**这一点容易让人怀疑"它不是普通金属"；磁性恰恰说明它是**金属**（Fe/Co/Ni），非金属从不被磁铁吸引。

### 图 3-6　例题：由位置推断性质｜Worked Example

**题目**：不查资料，预测第 4 周期第 14 族元素（Ge 锗）的性质，并说明依据。

| 步骤 Step | 推理 Reasoning | 结论 Conclusion |
|---|---|---|
| 1. 定位 | 第 14 族、第 4 周期，位于锯齿线上 | 属于 **metalloid 类金属** |
| 2. 同族类比 | 同族的 C 为非金属、Si 为类金属、Sn/Pb 为金属 → 越往下金属性越强 | Ge 处于中间，性质**介于两者之间** |
| 3. 性质预测 | 类金属通性：有暗淡金属光泽、**脆、不可延展**、semi-conductor | 外观灰白、敲击会碎、导电性弱于金属但强于非金属 |
| 4. 状态 | 类金属在室温下均为固体 | 常温为固体 |
| 5. 自我验证 | 与"类金属常用于半导体工业"的事实一致 | Ge 是最早用于晶体管的材料之一 |

**答案**：Ge 锗为**固体类金属**，有暗淡金属光泽、脆性、半导体；依据是它在锯齿线上，以及"同族向下金属性增强"的规律。

## 8. 常见易错点｜Common Misconceptions

| # | 错误认识 Misconception | 正确理解 Correction |
|---|---|---|
| 1 | "H 在第 1 族，所以它是金属" | H 是**非金属**。它排在 1 族是因为**只有 1 个价电子**，位置由电子结构决定，不由金属性决定。 |
| 2 | "所有金属都是固体" | **Hg 汞**在室温下是液体。Ga（29.8 ℃）、Cs（28.4 ℃）稍热即熔。 |
| 3 | "金属都能被磁铁吸引" | 常温只有 **Fe、Co、Ni**（及其合金）具铁磁性；铜、铝、金都不会被磁铁吸。 |
| 4 | "能导电的一定是金属" | **石墨**（碳的一种形态）能导电却是非金属；盐水导电靠离子也不是金属。 |
| 5 | "类金属 = 一半金属一半非金属的混合物" | 类金属是**单一元素**，性质介于两者之间（半导体），不是混合物。 |
| 6 | "metalloid 与 semi-metal 是两类不同东西" | 两者**等价**；BC 官方用词是 **semi-metal**，中文统一译"类金属"。 |
| 7 | "周期表右边都是气体" | Br 是液体，C、P、S、I₂ 是固体。 |
| 8 | "把 group 和 period 记反了" | **group 是纵列（竖）**，**period 是横行（横）**；记忆：group 像一"组"人**站成一列**。 |
| 9 | "第 1 族就是表的第一横行" | 第 1 族是**第一纵列**（H、Li、Na、K…）；第一横行是**第 1 周期**（H 与 He）。 |
| 10 | "非金属一定软、一定轻" | 非金属中的**金刚石（碳）**极硬；碘晶体也不软。硬度不是分类依据。 |
| 11 | "同一横行的元素性质相似" | 同一**纵列（族）**才相似；同一横行（周期）是从金属渐变到非金属。 |

### 参考答案｜Answer Key

**A 组**
- A1. group / family 是周期表中的**纵列**；共有 **18** 个族。
- A2. period 是周期表中的**横行**；共有 **7** 个周期。
- A3. 任答四条：**lustrous/shiny 有光泽**；**malleable 有延展性（可压成薄片）**；**ductile 可拉成丝**；**good conductor of heat and electricity 导热导电**；室温多为固体（Hg 除外）；熔沸点较高。
- A4. 任答三条：**dull 无光泽**；**brittle 脆**；**poor conductor 不良导体**；多为气体。
- A5. **B 硼、Si 硅、Ge 锗、As 砷、Sb 锑、Te 碲**。
- A6. **Hg 汞（金属）** 与 **Br 溴（非金属）**；Hg 是其中唯一的液态金属。
- A7. **Fe 铁、Co 钴、Ni 镍**。
- A8. 第 **1、2、13、14、15、16、17、18** 族。
- A9. 第 **3–12** 族；例如 **Fe 铁、Cu 铜、Zn 锌**（或 Ag、Au、Ni、Cr、Mn）。
- A10. **错**。Hydrogen 是**非金属**。它位于第 1 族是因为它只有 1 个价电子，位置反映**电子排布**，而不是金属性。

**B 组（要点）**
- B1. (a) **metal 金属**；(b) 依据"有磁性"可锁定 **Fe 铁 / Co 钴 / Ni 镍**（三者之一）；(c) 它们属于**过渡元素**（第 8–10 族），其中 Fe 位于**第 4 周期第 8 族**。
- B2. P = **metal**；Q = **non-metal**；R = **metalloid**；S = **non-metal**（气体）；T = **metal**（具磁性，为 Fe/Co/Ni）。暴露问题的是 **R**（有光泽却脆、导电性中等）：若只看"能导电"，R 会被误判为金属；它说明**单一性质不足以分类**。
- B3. 错误在于：他把"同列位置"当成了"同性质类别"，跳过了对证据的检查。周期表确有"同族性质相似"的规律，但氢在常温常压下是**无色气体、不导电、不能延展**，不具备金属的任何典型特征，所以它是**非金属**。周期表仍把它放在第 1 族，是因为它只有 **1 个价电子**——位置反映的是**电子排布**，而不是金属性。这正是"位置 ↔ 电子结构"的体现，也是 Ch.5 的核心内容。
- B4. 问题：石墨虽然能导电，却**脆**（敲击即碎、不可延展）、导热与外观都不符合金属的典型特征；把它判成金属说明单一指标会导致误判。可靠做法是**综合多条性质**（光泽、延展性与脆性、导电导热性、常温状态、磁性）再做分类，必要时多做一次重复试验；同时要承认分类模型有边界与例外。

**C 组（评分要点）**
- C1. 满分要点：① **位置 ↔ 性质**：同族（纵列）性质相似、同周期由金属性过渡到非金属性，因此由坐标就能读出大致性质；② 预测实例：Mendeleev 留空位预测的 **Ga 镓 / Ge 锗 / Sc 钪**被陆续发现且性质吻合；或由第 14 族推断 Ge 是类金属半导体；或由第 1 族预测 Rb、Cs 极为活泼；③ 局限：**边界元素（Po、At、Al 旁侧）归属有争议**、**石墨能导电**等例外说明三类划分是**简化模型**，不能覆盖所有情况。三点齐全为满分。
- C2. 参考方案：自变量 = 样品编号；因变量 = 各项性质测试结果；控制变量 = 同一套电路与电池、相同锤击方式、相同光照条件。步骤：① 观察外观与光泽并记录；② 用磁铁靠近，记录是否被吸引；③ 接入电池-灯泡电路，记录灯泡亮度等级；④ 在垫木上锤击小块样品，记录"变薄 / 碎裂"；⑤ 综合判断。数据表应含光泽、磁性、导电等级、锤击结果、结论。判据：三者都导电/可延展/有磁性 → 金属；暗淡+碎裂+灯泡微亮 → 类金属；暗淡+碎裂+不导电 → 非金属。安全：护目镜；硅片锋利戴手套或由教师处理；不品尝、不吸入粉尘；锤击时严禁对人。

## 10. 回扣核心概念｜Connection to the Big Idea

> **Big Idea**：*The electron arrangement of atoms impacts their chemical nature.*
> **原子的电子排布决定其化学性质。**

本章的全部现象，最后都要追溯到电子：

1. **为什么同一族性质相似？** 因为主族元素**价电子数相同**——第 1 族都是 1 个，第 17 族都是 7 个。纵列不是随意画的，而是"电子排布相同者站成一列"。
2. **为什么沿一条横行金属性逐渐消失？** 因为从左到右价电子数逐次增加到 8，**得到/失去电子的倾向**随之改变，于是从金属渐变到非金属，最后到第 18 族的稀有气体。
3. **为什么同一族往下金属性增强？** 因为电子层越来越多，最外层电子离原子核越来越远、束缚变弱，**更容易失去** → 更"金属"（这条正是 Ch.4 活性趋势的原因）。
4. **Hg 是液体、类是半导体、石墨能导电**：这些"看似反常"的细节提醒我们——结构决定性质，而周期表只是这张结构地图的第一张素描。

**思考题（下章预热）**：既然同一族的性质相似，那么第 1 族的 Na 和 K 到底"相似"到什么程度——它们与水反应时，谁是"安静冒泡"，谁会"起火爆炸"？答案就在 Ch.4 的活性趋势里。
